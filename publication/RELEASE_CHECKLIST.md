# MCR Release Checklist

## Scientific closure

- [ ] Closure classification frozen
- [ ] Authoritative readback incorporated, or unresolved state explicitly frozen
- [ ] No historical runner replayed
- [ ] No historical authorization reused
- [ ] Claim/evidence matrix independently reviewed
- [ ] Original MCWS metrics unchanged
- [ ] Negative/partial R1.9B result preserved

## Evidence hygiene

- [ ] Approved evidence-copy list frozen
- [ ] Secret scan PASS
- [ ] Private-path scan PASS
- [ ] Authentication material excluded
- [ ] Customer/client material excluded
- [ ] Every included artifact hashed
- [ ] FROZEN_EVIDENCE_ANCHORS verified
- [ ] SHA256SUMS generated after final file set

## Manuscript

- [ ] Time-sensitive vendor/platform claims refreshed or explicitly dated
- [ ] Figures regenerated from approved sources
- [ ] PDF reviewed page-by-page
- [ ] Claim language matches evidence class
- [ ] R1.9B not described as completed live mutation
- [ ] Autonomous self-healing not claimed

## Archival release

- [ ] Version selected
- [ ] Git tag created
- [ ] GitHub release created
- [ ] Release ZIP attached
- [ ] Release ZIP hash published
- [ ] Zenodo archive minted
- [ ] CITATION.cff updated with DOI/date
- [ ] PUBLICATION_MANIFEST frozen
- [ ] Repository visibility intentionally set for release
